About FileGuard

Unified File Monitoring System

Overview

FileGuard is a comprehensive file monitoring and control system that combines cloud-based file sharing with local USB device management. It provides enterprise-grade security features including role-based access control, device registration, and complete audit trails.

Cloud Monitoring System

  • Google Drive Integration - Upload and manage files on Google Drive
  • OAuth 2.0 Authentication - Secure login with Google accounts
  • Permission Management - Assign specific files to specific users
  • IP-Based Access Control - Optional IP address verification

Local Monitoring System

  • USB Device Detection - Real-time monitoring of connected devices
  • Device Registration - Only registered devices can receive files
  • MAC + Password Auth - Hardware-level authentication security
  • Role-Based Access - SuperAdmin, Admin, and User roles

User Roles (Local System)

SuperAdmin

Register devices, manage all users, full system access

Admin

Grant device permissions to users, view logs

User

Transfer files only to authorized devices

Technology Stack

Python Flask Flask-SocketIO SQLite Google OAuth 2.0 Google Drive API WMI (Windows) Tailwind CSS
